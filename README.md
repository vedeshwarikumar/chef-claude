# Chef Claude

Chef Claude is a React web app that suggests a recipe based on the ingredients you have. Add your ingredients, click **Get recipe**, and the AI replies with a recipe you can cook.

**Live demo:** _add your Vercel link here_

## Features

- Add ingredients to a list and remove any of them with a right-click
- Dropdown of recently used ingredients when you click the input box (saved in the browser)
- "Get recipe" button appears once you have added 4 or more ingredients
- Recipe generated by the Google Gemini API and shown as formatted markdown
- Loading state and error message while the recipe is being fetched
- API key kept safe on the server, never exposed in the browser

## Tech stack

- React (components, hooks, `useState`, `useEffect`)
- Webpack and Babel
- `react-markdown` to display the recipe
- Google Gemini API
- Vercel serverless function (`api/recipe.js`) to keep the API key private
- Deployed on Vercel

## Run it locally

1. Clone the repository
   ```
   git clone https://github.com/YOUR_USERNAME/chef-claude.git
   cd chef-claude
   ```
2. Install the packages
   ```
   npm install
   ```
3. Start the app
   ```
   npm start
   ```
   The app opens at `http://localhost:3000`.

`npm start` runs only the front end, so the recipe button needs the `api` function. To test the full app on your computer, create a `.env` file with your key and use the Vercel CLI:

```
GEMINI_API_KEY=your_key_here
```
```
npx vercel dev
```

## Deploy

1. Push the project to GitHub.
2. Import the repository on [vercel.com](https://vercel.com).
3. Set the build command to `npm run build` and the output directory to `dist`.
4. Add an environment variable named `GEMINI_API_KEY` with a key from [Google AI Studio](https://aistudio.google.com).
5. Click **Deploy**.
